# 广西民族大学机器人设计组

GXMZU Robot Design Group · 机器人结构、电控与算法协同开发。

## 方向

| 方向 | 内容 |
| :--- | :--- |
| 结构 | 底盘、执行机构、轻量化与装配 |
| 电控 | 主控、驱动、传感器与通信 |
| 算法 | 感知、定位、运动规划与控制 |

## 协作

- 规范见 [guidelines](https://github.com/GXMZU-RD/guidelines)：分支模型、PR 红线、评审与权限。
- 提交前按 `.github/PULL_REQUEST_TEMPLATE.md` 自查。
- 一题一 Issue：功能提案写清「要什么 / 怎么用 / 验收标准 / 不做什么」。

## 成员

入组后由管理员分配对应项目组权限；看不到某个仓，说明还没进那个组。
